Build a story, then publish it as a public GitHub Gist in the GOCHATAPP format (GOCHATAPPSTORYTAG_<story>.md, character_*.txt, storyelement_*.txt and thumbnails). Anyone who installs the gist gets the story, its characters, its elements and its images.

4. IMAGE ASSIGNMENT

Pick a story, character, or story element, then upload or paste an image below.

Upload or Ctrl+V paste — resized to 450x450 JPEG, then uploaded to ImgBB when you publish.

Loads a story back into this form so you can edit and re-publish it.

Every publish creates a new public gist (an existing gist is never overwritten). "Install Locally" downloads the current gist into chats_stories/stories/ so the bot can use it.
