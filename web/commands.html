Commands Reference

Character.XI Bot Controls

Home
Commands start with a dot. Use the shown arguments where needed. On Web, prefix with a dot (e.g. .help). In Telegram the dot is required too, unless lazy mode is on (.lazy / .lz).

Help & Roles

.help / .h
Show this command list
.role / .r
List roles; .role N switches role
.role i / .role image / .r i / .r image
List all roles with their images
.reload
Reload the current role
.image
Show the current role's image
.rs [N] / .rolesummary [N]
Summarize the current role (optional prompt N)
.roles
List all available roles (chat mode only)

Personas (user identity)

.persona / .per
List personas; .persona N switches persona
.persona i / .persona image
List all personas with their images
.persona clear
Clear the current persona

Providers & Models

.provider / .p
List providers; .provider N switches provider
.model / .m
List models; .model N switches model
.mf [NAME|n|next|prev] / .modelsfiltered
Filter/select models on any provider
.think
Toggle think mode
.llmctx [Nk] / .mc / .mcontext
Show/set the context size, e.g. 8k

Stories

.story select
List stories; .story select NAME|N activates one
.story save NAME / .store save NAME
Save assistant story text
.stories / .st
List stories (story mode only); .st [N] selects a story
.stories image / .stories i
Show story thumbnails
.char
List characters; .char [N|NAME] [on|off] toggles one
.char all off
Deactivate all characters
.char edit N / .char save NAME TEXT
Show a character bio, or save one
.element / .el
List story elements
.element [N|NAME] [on|off] / .element all off
Toggle a story element, or deactivate all of them
.element edit N / .element save NAME TEXT
Show a story element, or save one
.install GIST_ID_OR_URL
Install a role or story from a GitHub Gist

Chats & History

.chat / .chats / .c
List saved chats
.chat save NAME / .chat load NAME
Save or load a chat
.clear
Clear conversation memory; backs up the chat or story first
.clean / .cl
Clear memory, back it up, and remove the chat messages
.mode [chat|story] / .mo
Show or change the mode
.recap [N]
Summarize the last 50 messages, with optional prompt N
.ask QUESTION
Ask about conversation history
.last [N]
Show recent messages (3 by default)
.length [N] / .len [N] / .l [N]
Set the target response length (~N words); .length clear resets
.del
Delete the last exchange
.resend
Retry the last user message
.context [NUMBER]
Show/set the history context limit

Settings & Status

.status / .s
Show current settings
.verbose / .v
Toggle response details
.trace [on|off]
Toggle request tracing
.lazy / .lz
Toggle commands without the dot

Voice (text to speech)

.voice / .voice on|off
Toggle spoken replies
.voice [1-10]
Set speed: 1 = normal, 2 = 1.2x, 9+ = 1.9x; decimals like 1.5 work
.nar / .narrator
List voices with numbers, current voice and speed
.nar [n|name]
Select a voice, e.g. .nar 3 or .nar sonia

Synonyms

h=help, r=role, per=persona, p=provider, m=model, mf=modelsfiltered, mc / mcontext=llmctx, store=story, st=stories, el=element, c / chats=chat, cl=clean, mo=mode, s=status, v=verbose, len / l=length, lz=lazy, narrator=nar
